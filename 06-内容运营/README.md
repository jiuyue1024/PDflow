# 内容运营工作流（V1）

> 每天 5 分钟，持续输出。

---

## 第一步：每天记录（5 分钟）

打开 `changelog.md`，回答三个问题：

1. 今天修了什么？
2. 今天发现什么问题？
3. 今天为什么这样改？

记录够 3-5 条，就可以生成一篇帖子。

---

## 第二步：选定帖子类型

| 类型 | 推荐度 | 适合场景 | 目标 |
| :--- | :--- | :--- | :--- |
| 开发日志 | ⭐⭐⭐ | 日常进度、技术优化 | 互动讨论 |
| 案例帖 | ⭐⭐⭐ | 用户故事、使用场景 | 证明价值 |
| 失败复盘 | ⭐⭐⭐ | 踩坑经历、翻车现场 | 引发共鸣 |

---

## 第三步：一帖多发（30 分钟）

1. 在 `posts/` 下新建 `post_xxx.md`
2. 写好完整版
3. 按平台调整格式

| 平台 | 风格 | 长度 |
| :--- | :--- | :--- |
| 小红书 | 短平快、带表情 | 300-500 字 |
| Nodeloc | 技术细节、代码片段 | 500-800 字 |
| 微信公众号 | 故事感、情绪共鸣 | 1500-2000 字 |
| GitHub Discussion | 简洁英文 | 200-400 字（英文） |

**内容比例：** 70% 过程 + 20% 结果 + 10% 产品链接

不要：下载地址放第一句。

---

## 目录结构

```
marketing/
├── ideas.md          # 内容灵感收集
├── users.md          # 用户故事 & 反馈
├── changelog.md      # 开发日志（素材来源）
├── screenshots/      # 截图素材
└── posts/            # 帖子成品
    └── post_001.md   # 示例帖（三类 + 分发模板）
```
