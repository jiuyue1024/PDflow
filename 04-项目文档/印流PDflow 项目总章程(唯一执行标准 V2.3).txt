## 第三部分:项目核心定义与边界

### 3.1 项目定位
- **产品名:** 印流PDflow
- **核心价值:** 一站式PDF解决方案 - 日常办公用免费工具箱,专业排版用设计模块
- **差异化:** 比纯办公工具多一个"设计排版"能力;比纯设计工具多一套"免费工具箱"引流

### 3.2 品牌资产红线
- **LOGO状态:** **已有成品LOGO**(位于 `02-素材资源/`)
- **AI禁令:** 严禁生成、设计、修改、提议更换或手绘LOGO
- **强制使用:** 所有界面、打包图标100%使用现有LOGO

### 3.3 功能开发边界
**✅ 允许做的范围:**
- 修复Bug、性能优化、代码模块化
- 按 `DESIGN.md` 设计规范优化 UI
- 基于 PySide6 框架新增功能页面
- 在工具箱稳定后,新增设计排版模块

**❌ 严禁做的范围:**
- 删除或破坏现有后端 API 的任何功能
- 私自新增《总章程》未规划的无关功能
- 修改原有业务逻辑(PDF处理、导出等)
- **使用任何旧框架代码作为运行时依赖**
