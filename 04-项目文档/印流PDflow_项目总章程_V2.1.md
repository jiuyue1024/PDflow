## 第五部分:代码开发统一规范(Flet 版)

1. **文件命名与入口:**
   - 主程序入口:`src/flet_main.py`
   - 启动命令:`python flet_main.py`(需在 `src/` 目录下执行,或使用虚拟环境)

2. **后端复用规则:**
   - `src/api/__init__.py` 是唯一后端代码,所有 PDF 处理功能均在其中
   - Flet 前端通过调用 `PdfApi()` 实例来使用后端功能
   - **严禁修改后端 API 的函数签名**,只允许新增函数或修复Bug

3. **虚拟环境:**
   - 项目使用 `venv/` 作为 Python 虚拟环境
   - 安装新依赖时需先激活:`venv\Scripts\activate`

4. **缓存清理规则:**
   - 每次运行或打包软件前,必须清除所有 `__pycache__` 缓存文件夹和 `.pyc` 编译文件,防止旧缓存干扰新代码
   - 清理命令:
     ```powershell
     # 在项目根目录执行
     Get-ChildItem -Path . -Recurse -Directory -Filter "__pycache__" | Remove-Item -Recurse -Force
     Get-ChildItem -Path . -Recurse -Filter "*.pyc" | Remove-Item -Force
     ```

### 6.3 自动备份规则

#### 方案A：代码内嵌自动备份（已实装）
- `src/main_flet.py` 中的 `auto_backup()` 函数会在软件每次启动时自动执行
- 将 `src/` 下所有 `.py` 文件复制到 **`F:\印流PDflow项目\04-项目文档\backups\当天日期\`** 目录
- 每天只备份一次（同一天内不重复备份）
- 备份失败只在控制台打印错误日志，不影响软件正常使用

#### ⚠️ 备份路径规则（强制）
- **固定备份目录：** `F:\印流PDflow项目\04-项目文档\backups\`
- 备份文件必须按 `当天日期` 建立子文件夹，如 `2026-04-30/`
- 禁止将备份散落在其他位置或打乱原有文件夹结构
- AI助手每天按此规则执行备份，不允许更改目标路径

#### 方案B：AI助手主动提醒
- **每次对话开始时**：检查 `04-项目文档/backups/当天日期/` 是否存在，如不存在则提醒用户：“今日尚未备份源码，是否需要我立即备份？”
- **用户确认备份时**：执行源码备份，将 `src/` 复制到对应备份目录
- **用户说“下班”“今天到这”“明天继续”时**：主动确认备份是否完成，未完成则提醒
