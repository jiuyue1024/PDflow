\\\python
def _on_card_clicked(self, template_name):
    dialog = TemplateEntryDialog(template_name, self)
    result = dialog.exec()
    if result == QDialog.Accepted:
        # 找到对应的 template_id
        template_id = self._name_to_id(template_name)
        self.editor_requested.emit(template_id)

def _name_to_id(self, name: str) -> str:
    for t in self._templates:
        if t["name"] == name:
            return t["id"]
    return ""

## 子任务 6：TPL-05 文件上传嵌入功能

### 痛点
当前表单只支持手动输入，设计师在实际工作中经常需要把已有文件（如品牌Logo、签名图片、产品图）直接上传并嵌入到生成的模板中。

### 需求
表单中需要添加上传按钮，支持选择常见文件格式（如 .png, .jpg, .pdf）。上传后，文件可以插入到模板的指定区域（如名片中的Logo位、产品规格页的图片位等）。

### 交互
点击"上传文件"按钮 → 系统弹出文件选择对话框 → 用户选择文件 → 文件预览图出现在表单中 → 用户可拖动调整其顺序和位置。

### 验收
- 支持的格式（.png/.jpg/.pdf）能正确上传与预览
- 上传的图片能正确嵌入到最终生成的PDF中
- 上传的文件在PDF中位置和大小符合预期

## 子任务 7：TPL-06 导出时弹出文件夹选择保存路径

### 痛点
当前导出可能默认保存到了某个固定目录，用户找不到文件，这不符合专业软件的操作习惯。

### 需求
所有导出功能（点击"生成PDF"后），必须弹出一个文件夹选择对话框，让用户自己决定把文件保存在哪里。

### 交互
点击"生成PDF" → 文件生成完后 → 自动弹出系统原生的文件夹选择对话框 → 用户选择目标文件夹 → 点击"确定" → 文件保存到该路径。

### 验收
- 每次导出都弹出对话框
- 文件被正确保存到用户指定的文件夹
- 不弹出对话框或保存路径错误则为失败
