# 印流PDflow 新版模板开发工作流

> **版本:** V1.0  
> **生效日期:** 2026-05-12  
> **适用范围:** 所有新模板的开发与优化

---

## 一、设计先行工作流

所有新模板开发必须遵循以下三步流程：

### 阶段 1：设计先行

**触发条件:** 用户指定一个参考风格（如"瑞士国际主义平面设计风格"）

**AI 必须输出至少 3 版不同的版式草图**，每版草图需清晰展示：

| 展示要素 | 说明 |
| :--- | :--- |
| 字体层级 | H1/H2/H3/Body/Caption 的字号、字重对比 |
| 留白 | 页边距、内边距、元素间距的具体数值 |
| 图片区 | 图片占位框的尺寸、位置和比例 |
| 视觉重心 | 哪个区域是第一视觉落点，为什么 |

**输出格式要求:**
```
### 方案 A：[风格名称]
- 设计理念：[一句话说明]
- 布局特征：[描述网格结构、对齐方式]
- 字体层级：[列出具体的字号和字重]
- 间距体系：[列出关键间距值]
- 视觉动线：[描述用户视线的流动路径]
- 适用场景：[什么类型的文档最适合]
```

### 阶段 2：人工定调

**用户操作:**
- 选择其中一个设计方向
- 或提出修改意见（如"方案A的标题太大，缩小到20px"）

**AI 响应:**
- 根据用户反馈调整方案
- 输出修正后的设计稿
- 等待用户确认

### 阶段 3：生成与验证

**触发条件:** 用户确认设计方向

**AI 必须生成:**
1. **模板 JSON 文件**（`assets/templates/{template_id}.json`）
   - 字段定义（fields）
   - 样式选项（style_options）
   - 预设数据（可选）

2. **PDF 渲染代码**（`src/common/template_renderer.py`）
   - 对应 `render_{template_id}` 函数
   - 支持所有样式选项
   - 包含完整的错误处理

3. **编辑器集成**（`pages/template_editor_page.py`）
   - CSS 预览模板
   - 样式控制面板
   - 字段分组（如适用）

4. **自检测试**
   - 验证所有字段能正常填写
   - 验证所有样式选项能正常切换
   - 验证 PDF 能正确生成

## 二、设计审查机制

所有模板代码在交付前，**必须通过设计审查**。审查分为四个维度：

### 2.1 间距审查

| 检查项 | 标准 | 判断方法 |
| :--- | :--- | :--- |
| 页面外边距 | ≥ 24px | 检查最外层容器 margin |
| 卡片内边距 | ≥ 20px | 检查卡片 padding |
| 卡片间距 | ≥ 16px | 检查卡片间 gap/margin |
| 元素组间距 | ≥ 12px | 检查同组控件间距 |
| 紧凑间距 | ≥ 8px | 检查紧密相关元素 |
| 拥挤检测 | 无重叠、无贴边 | 视觉检查或代码计算 |

**违规处理:** 发现间距 < 标准值 80%，判定为 🟡 建议修复

### 2.2 字体审查

| 检查项 | DESIGN.md 标准 | 判断方法 |
| :--- | :--- | :--- |
| H1 主标题 | 24px, Bold (700) | 检查 fontSize + fontWeight |
| H2 区块标题 | 18px, SemiBold (600) | 检查 fontSize + fontWeight |
| H3 卡片标题 | 15px, SemiBold (600) | 检查 fontSize + fontWeight |
| Body 正文 | 14px, Regular (400) | 检查 fontSize + fontWeight |
| Caption 辅助 | 12px, Regular (400) | 检查 fontSize + fontWeight |
| Button 按钮 | 14px, Medium (500) | 检查 fontSize + fontWeight |
| 层级分明 | 相邻层级字号差 ≥ 3px | 计算 H1-H2, H2-H3, H3-Body |
| 字重差异 | 相邻层级字重差 ≥ 100 | 计算 Bold-SemiBold, SemiBold-Regular |

**违规处理:**
- 字号偏离 > 2px → 🟡 建议修复
- 字重层级混乱 → 🔴 必须修复
- 相邻层级无差异 → 🔴 必须修复

### 2.3 视觉重心审查

| 检查项 | 标准 | 判断方法 |
| :--- | :--- | :--- |
| 主标题突出 | 页面中最大、最重的文字 | 字号 ≥ 20px，字重 ≥ 600 |
| 信息优先级 | 重要信息 > 次要信息 > 辅助信息 | 通过字号、颜色、位置体现 |
| 对称/平衡 | 左右/上下视觉重量均衡 | 不出现一侧明显"空"或"重" |
| 引导明确 | 用户视线有明确的阅读路径 | 从上到下、从左到右、从大到小 |
| 留白充足 | 关键信息周围有足够呼吸空间 | 无"挤成一团"的观感 |

**违规处理:**
- 主标题不突出 → 🟡 建议修复
- 信息优先级混乱 → 🟡 建议修复
- 严重失衡 → 🔴 必须修复

### 2.4 色彩审查

| 检查项 | DESIGN.md 标准 | 判断方法 |
| :--- | :--- | :--- |
| 页面背景 | #0A0A0F（深色）/ #F5F5F7（浅色） | 检查 background-color |
| 卡片背景 | #14141A（深色）/ #FFFFFF（浅色） | 检查卡片样式 |
| 主文字 | #ECEDF0（深色）/ #1D1D1F（浅色） | 检查 color 属性 |
| 次文字 | #8B8D98（深色）/ #6E6E73（浅色） | 检查辅助文字颜色 |
| 主题色 | #4D7CFE | 检查按钮、链接、选中态 |
| 对比度 | WCAG AA 标准（≥ 4.5:1） | 使用对比度计算工具 |

**违规处理:** 色彩偏离 → 🟡 建议修复
