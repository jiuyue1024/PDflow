## 需求分析

### 需求 A：notice 模板样式选项

#### 痛点与需求
- 当前 notice（单页公告）模板没有 `style_options`，渲染风格硬编码为"深蓝装饰条 + 白底 + 灰辅助色"，无法满足不同场景的视觉需求（如喜庆通知、紧急公告、正式公文等）
- 用户需要在表单填写时就能选择风格，预览区实时反映变化

#### 功能描述
为 notice 模板添加样式选项系统，参照 business_card 模板的 `style_options` 设计，但针对公告场景做定制调整。

#### 交互逻辑
1. 用户在模板编辑器选择「单页公告」模板
2. 表单区下方出现「样式设置」卡片
3. 用户点击主题色色块 → 顶部装饰条、标题下划线、分隔线颜色同步变化，预览区实时更新
4. 用户切换装饰条位置 → 装饰条位置实时变化
5. 用户切换背景样式 → 背景颜色/渐变实时变化
6. 用户切换字体风格 → 正文字体大小和颜色微调

#### 验收标准
- notice.json 包含完整 `style_options` 字段
- `template_editor_page.py` 能正确解析并渲染 notice 的样式选项 UI
- `render_notice()` 函数接收 `style` 字典参数，按样式渲染 PDF
- 预览区 HTML 根据样式选项实时刷新
- 生成的 PDF 体现样式变化（装饰条颜色/位置、背景、字体风格）
- 不影响现有 business_card 和 product_spec 模板功能

### 需求 B：notice / product_spec 实时预览

#### 痛点与需求
- 当前 `_update_preview()` 方法只实现了 `business_card` 的实时 HTML 预览
- notice 和 product_spec 模板的预览区显示「预览功能开发中」占位符，用户无法实时看到填写效果
- 必须生成 PDF 才能看到最终效果，交互体验断裂

#### 功能描述
为 notice 和 product_spec 模板实现实时 HTML 预览，与 business_card 的预览模式一致：用户填写表单时，右侧预览区实时渲染近似 PDF 的 HTML 预览。

#### 交互逻辑
1. 用户在模板编辑器选择 notice 或 product_spec 模板
2. 右侧预览区从「预览功能开发中」变为对应的实时 HTML 预览
3. 每次字段内容变化（输入、修改、删除），预览区自动刷新
4. notice 预览需响应样式选项变化（主题色、装饰条位置、背景、字体风格）
5. product_spec 预览需展示表格数据

#### 验收标准
- notice 模板：预览区实时显示公告排版效果（标题、日期、正文、发布单位、装饰条、背景色等）
- product_spec 模板：预览区实时显示产品规格排版效果（产品名、版本、描述、规格表格）
- 预览 HTML 与 PDF 渲染效果视觉一致（布局、配色、字号比例）
- 输入时无卡顿（防抖 ≤ 300ms）
- 不影响 business_card 已有的预览功能

在现有 fields 数组之后添加 `style_options` 字段，结构如下：

```json
{
  "id": "notice",

        {"name": "玫瑰金", "value": "#B76E79"}
      ]
    },
    "bar_position": {
      "label": "装饰条位置",
      "type": "radio",
      "default": "top",

        {"name": "纯白", "value": "white"},
        {"name": "浅灰", "value": "light_gray"},
        {"name": "浅蓝", "value": "light_blue"},

      ]

        {"name": "正式公文", "value": "formal"},
        {"name": "简约现代", "value": "modern"},
        {"name": "醒目强调", "value": "bold"}
      ]
    }
  }

```

**设计说明**：
- `theme_color`：默认 `#2C3E6B`（当前硬编码的深蓝色），提供 9 种预设色
- `bar_position`：公告场景顶部装饰条最常见，默认 `top`；增加 `left` 竖条选项
- `bg_style`：增加 `light_blue`（浅蓝底，公文感），不包含名片模板的 `gradient_horizontal`（A4 横向渐变不自然）
- `font_style`：公告专属选项——正式公文（宋体风/小号间距）、简约现代（无衬线/正常间距）、醒目强调（加粗标题/大号）
- **不包含** `bg_texture`（公告背景纹理不合适）和名片模板的其他无关选项

### 任务 2：更新 render_notice() 函数签名与逻辑

**文件**：`F:\印流PDflow项目\src\common\template_renderer.py`

**修改函数签名**：

```python
def render_notice(output_path: str, data: dict, image_path: str = None, style: dict = None) -> str:
```

**新增 style 参数处理逻辑**：

```python
style = style or {}
theme_color = style.get("theme_color", "#2C3E6B")
bar_position = style.get("bar_position", "top")
bg_style = style.get("bg_style", "white")
bg_custom_color = style.get("bg_custom_color", "")
font_style = style.get("font_style", "formal")
```

**渲染逻辑调整**：

1. **主题色**：将硬编码的 `theme_rgb = (0.15, 0.25, 0.45)` 改为根据 `theme_color` 动态计算，使用已有的 `_hex_to_rgb()` 函数
2. **装饰条位置**：
   - `top`（默认）：保持现有顶部横条逻辑
   - `bottom`：改为页面底部画横条
   - `left`：左侧画竖条（宽度 3mm，从顶部 margin 到底部 margin）
   - `none`：不画装饰条
3. **背景样式**：
   - `white`：保持现有白底
   - `light_gray`：填充 `#F5F5F5`
   - `light_blue`：填充 `#EBF0FA`
   - `gradient_vertical`：从 `#FFFFFF` 渐变到 `#F0F0F5`
4. **自定义背景色**：如 `bg_custom_color` 非空，覆盖 bg_style 的背景
5. **字体风格**：
   - `formal`：标题 24pt + 正文 12pt + 行距正常（当前默认）
   - `modern`：标题 20pt + 正文 11pt + 行距稍紧
   - `bold`：标题 28pt 加粗 + 正文 13pt + 标题下划线加粗
