## 3. 正面布局规范

### 3.1 边距体系

```
┌────────────────────────────────────────┐
│            ← 12% top margin →          │
│                                        │
│   ← 15%          [LOGO]         15% →  │
│                                        │
│              姓名 28~36pt               │
│              英文名 (可选)               │
│                                        │
│              职位 12pt                  │
│                                        │
│          联系方式组（居中）              │
│        ☎ 138-0000-0000                │
│        ✉ name@company.com              │
│                                        │
│            ← 12% bottom margin →       │
└────────────────────────────────────────┘
```

### 3.2 坐标参数

| 元素 | 坐标/位置 | 字号 | 颜色 |
|---|---|---|---|
| Logo | 距顶 18%（中心点），水平居中 | 8.0mm（可配置） | 图片 |
| 姓名 | Logo 下方 +12pt 间距 | 28~36pt（动态） | 主色 |
| 英文名 | 姓名下方 +8pt | 10pt | 次要色 |
| 职位 | 英文名下方 +6pt | 12pt | 次要色 |
| 联系方式 | 职位下方 +10pt | 10pt + 16pt 行间距 | 主色 |

### 3.3 姓名动态字号

| 姓名长度 | 字号 |
|---|---|
| ≤ 3 字 | 36pt |
| 4~6 字 | 32pt |
| > 6 字 | 28pt |

## 4. 背面布局规范（方案A）

### 4.1 版式结构

```
┌────────────────────────────────────────┐
│            ← 12% top margin →          │
│                                        │
│              [LOGO]                    │
│              ↓ +12pt                   │
```

### 4.2 坐标参数

| 元素 | 坐标/位置 | 尺寸 | 颜色 |
|---|---|---|---|

| 二维码 | Logo 下方 +12pt，水平居中 | 14.0mm | 图片 |
| 二维码说明 | 二维码下方 +4pt | 9pt | 次要色 |

## 5. 双面渲染

### 5.1 参数

```python
render_business_card(
    output_path="output.pdf",
    data={"name_cn": "张三", ...},
    logo_path="logo.png",
    qr_image_path="qr.png",
    render_sides=["front", "back"],  # 双面
    # 或 render_sides=["front"]      # 仅正面
    # 或 render_sides=["back"]       # 仅背面
)
```

### 5.2 输出

| render_sides | 输出 PDF 页数 | 说明 |
|---|---|---|
| `["front"]` | 1 页 | 仅正面 |
| `["back"]` | 1 页 | 仅背面 |
| `["front", "back"]` | 2 页 | 双面（正面→背面） |

## 7. 技术实现

### 7.1 百分比坐标体系

所有布局使用百分比而非固定 mm 值：

```python
margin_top_pct = 0.12       # 上边距 12%
margin_bottom_pct = 0.12    # 下边距 12%
margin_side_pct = 0.15      # 左右边距 15%

center_x = width_pt * 0.50  # 全部 CenterAlign
```

### 7.2 字号体系（严格固定）

| 用途 | 字号 | 类型 |
|---|---|---|
| 姓名 | 28/32/36pt | 动态（根据长度） |
| 职位 | 12pt | 固定 |
| 英文名 | 10pt | 固定 |
| 联系方式 | 10pt | 固定 |
| 二维码说明 | 9pt | 固定 |
| 背面简介 | 10pt | 固定 |

### 7.3 行间距体系

| 用途 | 行间距 |
|---|---|
| 联系方式组 | 16pt |
| 背面简介 | 15pt |
