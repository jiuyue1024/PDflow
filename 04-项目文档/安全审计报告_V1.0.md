| M2 | `pages/speedwrite_page.py` | 14 | B314 | `ET.XMLParser()` 回退构造（无 `resolve_entities=False`），更易受 XML 攻击 | CWE-20 |

**修复建议（M1-M3）：**

将 `xml.etree.ElementTree` 替换为 `defusedxml`（已安装于虚拟环境中），或调用 `defusedxml.defuse_stdlib()`：

```python
# 方案 A：使用 defusedxml 替换
from defusedxml.ElementTree import fromstring as safe_fromstring

def _safe_xml_parse(data):
    return safe_fromstring(data)

# 方案 B：在程序入口调用 defuse_stdlib()
import defusedxml.ElementTree
defusedxml.ElementTree.defuse_stdlib()
```
