# PDFlow - 使用说明

## 软件简介

**PDFlow（印流）** 是专为外贸电商美工设计师打造的PDF工具，解决日常PDF处理痛点：
- PDF太大传不上阿里国际站
- 批量处理产品图效率低
- 需要提取PDF中的图片素材
- 合并多个PDF制作产品目录

## 快速开始

### 方式1：双击运行（推荐）
直接双击 `启动PDFlow.bat` 文件即可启动软件。

### 方式2：命令行运行
```bash
cd PDFlow
python main.py
```

## 功能模块

### 📁 浏览
PDF阅读器，支持：
- 打开和预览PDF文件
- 缩放、翻页、适应窗口
- 查看文件信息

### 🔄 转换
格式转换中心，支持：
- **智能压缩**：自动压缩到指定大小（如<5MB适合阿里国际站）
- **PDF转图片**：将PDF页面导出为高清图片
- **图片转PDF**：批量图片合并为PDF目录
- **提取图片**：从PDF中提取所有图片素材
- **设计师预设**：阿里国际站/Google独立站/印刷/邮件等预设配置

### ➕ 合并
PDF合并与拆分，支持：
- **合并PDF**：将多个PDF按顺序合并
- **按页数拆分**：如每5页拆分为一个文件
- **提取页面**：指定页码范围提取（如 1,3,5-10）

### ✎ 编辑
PDF编辑工具，支持：
- **添加水印**：文字水印，可调节透明度
- **页面旋转**：左转/右转/旋转180°
- **压缩优化**：多级别压缩选项
- **OCR文字提取**：提取PDF中的文字内容
- **元数据编辑**：修改标题、作者等信息

### ⚙️ 设置
- 默认输出目录设置
- 界面主题切换
- 预设管理

## 常见问题

### Q: 软件打不开？
A: 请确保已安装Python 3.8或更高版本。首次运行时会自动安装依赖包。

### Q: 如何压缩PDF到5MB以内？
A: 在「转换」面板选择PDF文件，选择「阿里国际站」预设，点击「PDF压缩」按钮。

### Q: 如何批量将图片转为PDF？
A: 在「转换」面板点击「选择图片」，选中所有图片后点击「图片转PDF」按钮。

### Q: 如何合并多个PDF？
A: 在「合并」面板添加多个PDF文件，调整顺序后点击「开始合并」。

## 技术信息
