## 需求分析

### 核心需求：样式预设系统

#### 痛点
- 当前样式控件分散（颜色、装饰条、背景、纹理等逐个选择），用户需要逐项搭配才能得到满意效果
- 没有推荐搭配方案，新手用户不知道哪些组合好看
- 三个模板的样式系统不统一：business_card 有 style_options，notice 和 product_spec 没有

#### 功能描述
建立「样式预设系统」：将样式控件整合为一个"样式方案"下拉选择框 + 保留的手动微调控件。选择预设后一键应用全部样式；手动修改任何参数后自动切换为"自定义"。

#### 交互逻辑
1. 用户进入模板编辑器 → 样式设置区顶部出现「样式方案」下拉框
2. 下拉框选项：极简白 / 商务蓝 / 醒目红 / … / ──自定义──
3. 选择预设 → 所有样式控件自动设为预设值 → 预览区实时更新
4. 手动修改任何样式参数 → 下拉框自动跳到「──自定义──」
5. 再次选择预设 → 覆盖手动修改，恢复预设值

#### 验收标准
- 预设文件独立存放于 `assets/templates/presets/` 目录
- 不修改原始模板 JSON 文件（notice.json / business_card.json / product_spec.json）
- 下拉选择预设后，所有样式控件同步更新
- 手动修改任何参数后，下拉框自动变为「自定义」
- 预览区实时反映预设或自定义效果
- 生成的 PDF 正确反映预设样式

### 关联需求：notice / product_spec 实时预览

#### 痛点
- notice 和 product_spec 的预览区显示「预览功能开发中」，用户必须生成 PDF 才能看到效果

#### 验收标准
- notice 和 product_spec 都有实时 HTML 预览
- 预览 HTML 与 PDF 渲染效果视觉一致

#### AT-06：升级 render_notice() 支持 style 参数

**文件**：`F:\印流PDflow项目\src\common\template_renderer.py`

**修改函数签名**：
```python
def render_notice(output_path: str, data: dict, image_path: str = None, style: dict = None) -> str:
```

**新增 style 参数处理**：
```python
style = style or {}
theme_color = style.get("theme_color", "#2C3E6B")
bar_position = style.get("bar_position", "top")
bg_style = style.get("bg_style", "white")
bg_custom_color = style.get("bg_custom_color", "")
font_style = style.get("font_style", "formal")
```

**渲染逻辑调整**：

1. **主题色**：硬编码的 `theme_rgb` 改为 `_hex_to_rgb(theme_color)` 动态计算
2. **装饰条位置**：
   - `top`（默认）：保持现有顶部横条
   - `bottom`：页面底部横条（y = height_pt - margin - bar_h）
   - `left`：左侧竖条（x = margin, 宽 3mm, 高度 = height_pt - 2*margin）
   - `none`：不画装饰条
3. **背景样式**：
   - `white`：白底 `(1,1,1)`
   - `light_gray`：`#F5F5F5`
   - `light_blue`：`#EBF0FA`
   - `gradient_vertical`：渐变（需在 PDF 中用多段 draw_rect 模拟，从 `#FFFFFF` 到 `#F0F0F5`）
4. **自定义背景色**：如 `bg_custom_color` 非空，用 `_hex_to_rgb()` 渲染，覆盖 bg_style
5. **字体风格**：
   - `formal`：标题 24pt + 正文 12pt + 行距 6mm（当前默认）
   - `modern`：标题 20pt + 正文 11pt + 行距 5mm
   - `bold`：标题 28pt + 正文 13pt + 标题下划线 2pt + 行距 7mm

**验收**：传入不同 style 字典能生成视觉差异明显的 PDF
