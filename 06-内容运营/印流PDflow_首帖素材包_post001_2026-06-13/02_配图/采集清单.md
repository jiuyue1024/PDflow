## 待采集截图（3 张）

### 截图 1：PyInstaller 打包输出 798MB
- **文件名：** `post_001_all_build_798mb.png`
- **平台共用：** 小红书 / Nodeloc / 公众号
- **怎么截：**
  1. 跑一次 PyInstaller 完整命令
  2. 终端输出里**关键三行**保留：
     - `INFO: Building EXE from EXE-00.toc completed successfully.`
     - `INFO: Build complete! results go to: ...\dist`
     - 文件大小行（**798MB** 这个数字必须清晰可见）
  3. 用截图工具截终端全屏或关键区域
  4. 标注 798MB（可用红色框或箭头简单标出）
- **小窍门：** PowerShell 终端用 `Get-Item dist\*.exe | Select-Object Name,Length` 单独取一次文件大小，截这两行更干净
- **质量要求：** PNG，分辨率 ≥ 1920×1080，数字清晰

### 截图 2：空壳 PySide6 hello world 打包对比
- **文件名：** `post_001_nodeloc_helloworld_baseline.png`
- **平台共用：** Nodeloc / 公众号
- **小红书不需要这张**（单图已够）
- **怎么截：**
  1. 新建空目录，写 5 行 PySide6 hello world：
     ```python
     from PySide6.QtWidgets import QApplication, QLabel
     app = QApplication([])
     QLabel("Hello").show()
     app.exec()
     ```
  2. 同样 `pyinstaller --onefile` 打包
  3. 截图终端输出（**约 220MB** 数字清晰可见）
- **用途：** 在 Nodeloc / 公众号正文里证明"不是我代码胖，是 PySide6 胖"
- **质量要求：** PNG，分辨率 ≥ 1920×1080
