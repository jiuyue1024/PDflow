# 印流PDflow 设计规范 DESIGN.md

## 一、品牌定位

- **产品名称**：印流PDflow
- **产品定位**：设计师专用的轻量级PDF排版与工具箱
- **品牌调性**：专业、简洁、现代、有设计感
- **目标用户**：平面设计师、UI/UX设计师、印刷出版从业者
- **设计目标**：让设计师在使用工具时，感受到与专业设计软件一致的高品质视觉体验

## 二、色彩系统

### 深色模式（默认）

| 用途 | 色值 | 说明 |
| :--- | :--- | :--- |
| 页面背景 | #0A0A0F | 深邃的蓝黑底色，减少视觉疲劳 |
| 侧边栏背景 | #0F0F14 | 比页面背景稍亮，形成层次 |
| 卡片/容器背景 | #14141A | 次级容器，浮于页面背景之上 |

| 卡片边框 | #1E1E28 | 细微边框，不抢眼 |
| 主要文字 | #ECEDF0 | 高对比度，保证可读性 |
| 次要文字 | #8B8D98 | 辅助信息、描述文字 |
| 禁用/占位文字 | #4A4B56 | 最低对比度 |
| 主题色（蓝） | #4D7CFE | 按钮、链接、选中态 |
| 主题色悬停 | #3D6CF0 | 按钮悬停时加深 |
| 成功绿 | #34C759 | 操作成功提示 |

## 三、字体体系

| 层级 | 字体 | 字号 | 字重 | 用途 |

| H1 | Inter / 思源黑体 | 24px | Bold (700) | 页面主标题 |

## 五、阴影与层级

| 层级 | 阴影值 | 使用场景 |
| :--- | :--- | :--- |
| 悬浮层 | `0 2px 8px rgba(0,0,0,0.15)` | 卡片、下拉菜单 |
| 模态层 | `0 8px 32px rgba(0,0,0,0.25)` | 对话框、弹窗 |
| 导航栏 | 无阴影，用颜色区分 | 侧边栏 |

- **设计理念**：采用扁平化设计为主，仅在高层级元素使用轻微阴影，保持界面干净轻盈。

## 六、核心组件规范

### 6.1 功能卡片（首页）

- 布局：响应式网格，桌面端一行4-5个卡片，平板端3个，手机端1-2个
- 每个卡片包含：图标（28px，主题色）+ 标题（15px，SemiBold）+ 描述文字（12px，次要文字色）
- 卡片背景：深色模式 #14141A，浅色模式 #FFFFFF
- 卡片圆角：12px
- 卡片内边距：20px
- 卡片悬停：背景微亮 + 边框变为主题色

### 6.2 侧边导航栏

- 宽度：220px（桌面端）
- 背景色：比页面背景稍亮一级
- 菜单项高度：44px
- 菜单项内边距：左侧16px
- 选中态：左侧3px宽主题色竖线 + 背景微亮
- 未选中态：文字为次要文字色，无背景
- 菜单项间距：2px
- LOGO区域：顶部24px外边距，LOGO居中或左对齐

### 6.3 按钮

| 按钮类型 | 背景 | 文字颜色 | 边框 | 圆角 |
| :--- | :--- | :--- | :--- | :--- |
| 主要按钮 | 主题色 #4D7CFE | 白色 | 无 | 8px |
| 次要按钮 | 透明 | 主题色 #4D7CFE | 1px solid 主题色 | 8px |
| 危险按钮 | #FF3B30 | 白色 | 无 | 8px |
| 文字按钮 | 透明 | 主题色 | 无 | - |

- 按钮高度：36px（默认），32px（紧凑）
- 按钮内边距：horizontal 16px, vertical 8px
- 悬停态：主要按钮加深至 #3D6CF0，次要按钮背景变为主题色10%透明度
- 禁用态：透明度40%

### 6.4 输入框与选择器

- 背景：深色模式 #0A0A0F，浅色模式 #FFFFFF
- 边框：1px solid（深色 #1E1E28，浅色 #E5E5EA）
- 圆角：6px
- 高度：36px
- 聚焦态：边框变为主题色 #4D7CFE，外发光 0 0 0 3px rgba(77,124,254,0.2)
- 内边距：horizontal 12px
- 占位文字：禁用/占位文字色

## 七、动效规范

- **过渡时间**：快速 150ms（按钮悬停），正常 250ms（卡片悬停、页面切换）
- **缓动函数**：ease-in-out（默认），ease-out（元素出现），ease-in（元素消失）
- **动效原则**：克制使用，不干扰操作流程。主要应用于悬停态切换、页面路由过渡、加载状态。

## 八、图标规范

- **图标库**：Material Icons（Flet内置）
- **图标尺寸**：导航菜单 20px，卡片 28px，按钮内 18px
- **图标颜色**：默认继承文字颜色，选中态/悬停态使用主题色
- **使用方式**：必须使用 `ft.Icons.XXX` 枚举形式，禁止使用字符串

## 九、Flet 0.84.0 编码规范（AI必须遵守）

1. 图标：使用 `ft.Icons.HOME` 枚举形式，不用字符串 `"home"`
2. 对齐：使用 `ft.alignment.center`，不用 `ft.controls.alignment.center`
3. 颜色：使用十六进制字符串 `"#4D7CFE"`，不用 `ft.Colors.BLUE`
4. 圆角：使用 `ft.border_radius.all(12)`
5. 内边距：使用 `ft.padding.all(20)` 或 `ft.padding.symmetric(horizontal=16, vertical=8)`
6. 文件选择器：统一使用项目自定义的 `TkFilePicker`，不使用 Flet 原生 `FilePicker`
7. 标签页切换：使用 `ft.Row` + 多个 `ft.ElevatedButton` 模拟，不使用 `ft.SegmentedButton`（该控件在0.84.0中不存在）
