## 标题

我做了个本地 PDF 工具，做到 beta 才发现，"能跑"和"能发布"是两件事

## 副标题

V1.1-beta 第一次打包，安装包 798MB 的故事

## 正文

### 一

过去几周我一直在做一件事：
把一个本地 PDF 工具做到"可以发布"的状态。

所谓"可以发布"，我心里的标准是：
- 模板排版能跑通
- 深浅色主题能切换
- PDF 合并、拆分、压缩、转换全部可用
- 打包成单文件可执行程序
- 装到别人电脑上也跑得起来

按这个清单，我一项一项做完了。

模板系统：选择 → 填写 → 预览 → 导出。
六个内置模板：名片、合同、发票、报告、公告、产品规格。
深浅色主题：跟系统走，也支持手动切。
PDF 工具箱：合并、拆分、压缩、转换，一套 PyMuPDF 跑完。

最后一步：打包。

我打开 PyInstaller，跑了一行命令。

### 二

输出文件大小：**798MB**。

我盯着这个数字看了很久。

第一反应是：是不是哪里配置错了？
是不是 spec 文件里多打了什么？
是不是图标、字体、样例 PDF 被无脑塞进去了？

我检查了一遍 spec。
逐项排除图标、字体、样例文件。
再跑一次。

**798MB。**

后来我做了一个最简单的实验：
新建一个空目录，写一个 PySide6 的 hello world 窗口，
`pyinstaller --onefile` 一把。

输出：**220MB+**。

这一刻我才意识到：

**不是我代码胖，是 PySide6 胖。**

不是我的逻辑有问题，
是这个赛道本身就重。

PySide6 + Qt 的核心运行时，
加上我们用到的 Qt 字体渲染、SVG、SQLite 驱动，
再加上早期评估时引入的 QtWebEngine 模块，
还有 PyInstaller 自身的 onefile 临时解压开销……

**这些加起来 798MB，是桌面软件这条赛道的"正常水位"。**

不是 bug。
是工程。

### 三

这件事让我重新想了一下"完成"这个词。

我做 Web 项目的时候，"完成"是清楚的：
- API 正常
- 能部署
- 监控接上
- 单元测试通过

那一刻，我就敢说"这个版本完了"。

但桌面软件不一样。

桌面软件的"完成"是一长串：
- 功能跑通 ✓
- 安装包体积 ≤ 150MB（我们项目自己的红线）
- 冷启动 ≤ 5 秒
- 跨 Windows 10 / 11 都能装
- 不强依赖 VC++ 运行库
- 主题在用户系统下不崩
- 日志能定位崩溃
- 卸载干净不留垃圾

**这一串清单里，"功能跑通"是 0 分。**
**"打包上线"才是 100 分。**
**中间这一段，过去我以为是"打包配置"，**
**实际是"产品工程"。**

### 四

我以前写过一行诗发到朋友圈：

> 写代码的爽感是即时的，
> 打包的挫败感也是即时的。

但这两件事之间的差距，可能比"从 0 到 1"还大。

Web 项目的部署，一句 `git push` + CI 就完了。
桌面软件的发布，是：
- 选打包模式（onefile / onedir / 各自优缺点）
- 算体积（依赖项逐一精算）
- 排字体（哪些内嵌、哪些走系统）
- 处理系统差异（高分屏 / 主题 / DPI）
- 处理运行库（VC++ / .NET / 字体）
- 测安装（干净机器 / 用户机器 / 升级路径）
- 测卸载
- 写升级策略

**这些事，每一件都不性感。**
**但少了任何一件，"发布"那一刻就会翻车。**

### 五

那 V1.1-beta 现在的状态是什么？

- 功能完成度：**100%**
- 安装包体积：**798MB**（**未达标**，差距 5 倍多）
- 已定的瘦身方向：
  - 剥离未使用的 QtWebEngine 模块
  - 拆分模块，按需加载
  - 改 `onedir` 模式
  - 字体子集化
  - 排查 hidden imports 冗余
- 目标：≤150MB（总章程红线）
- 预计 V1.1 正式版发布时间：**2-3 周内**

**V1.1-beta 暂不公开下载。**
先把体积压下来，再说发布。

这件事我选择先告诉大家，
而不是先把没做好的东西发出去。
独立开发最大的资本是信用。

### 六

最后想问问做桌面软件的朋友：

> 你们项目里，目前最大的体积来源是什么？
> - PySide6 / Qt 本身
> - 字体集合
> - ffmpeg / opencv 类大依赖
> - 打包模式选错
> - 其他

评论区聊聊，我准备这周把瘦身过程单独整理一篇，
看看哪条路最有效。

也欢迎你关注我，
我会持续更新这个本地 PDF 工具的瘦身日记，
直到 V1.1 正式版发出来。

—— 一个被 798MB 教育过的独立开发者
